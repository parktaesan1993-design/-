# 카우리테이블 캠페인 페이지 배포 가이드

고객용 페이지(카우리 이야기 · 에티켓 · 퀴즈와 쿠폰 · 함께 남기기)와 직원용 페이지(쿠폰 확인 · 댓글 관리 · 현황)가 들어 있습니다.
댓글과 쿠폰은 Netlify의 저장소(Netlify Blobs)에 저장되어 모든 고객이 함께 봅니다.

## 1. 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `public/index.html` | 고객용 페이지. 맨 아래 `SETTINGS`에서 매장 목록, 쿠폰 문구를 바꿉니다 |
| `public/staff.html` | 직원용 페이지 (관리자 PIN 필요) |
| `public/assets/` | 홍보영상, 영상 첫 화면 이미지 |
| `netlify/functions/` | 댓글·공감·퀴즈·쿠폰·관리자 기능 |
| `netlify/lib/quiz.mjs` | 퀴즈 문제·보기·정답·해설 (여기서 고치면 화면과 채점에 함께 반영) |
| `netlify/lib/store.mjs` | 저장소 연결, 댓글 금칙어 목록(`BLOCKED_WORDS`) |

## 2. 꼭 알아둘 점: 끌어다 놓기 배포는 안 됩니다

Netlify 화면에 폴더를 끌어다 놓는 방식(Netlify Drop)은 화면만 올라가고 **댓글·쿠폰 기능은 올라가지 않습니다.**
아래 두 방법 중 하나로 배포해 주세요. 처음이라면 **방법 A**가 간단합니다.

## 3. 방법 A — 명령어로 배포 (PC 한 대로 끝)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더(`kauri-app`)에서 명령 프롬프트(또는 터미널)를 엽니다.
3. 아래를 차례로 입력합니다.

```
npm install
npx netlify-cli login
npx netlify-cli init
npx netlify-cli deploy --prod
```

- `login`: 브라우저가 열리면 Netlify 계정으로 로그인합니다.
- `init`: "Create & configure a new project"를 고르고 이름을 정합니다 (예: `kyobo-kauri-table`). 빌드 명령은 비워 두고, 배포 폴더는 `public`을 그대로 둡니다.
- `deploy --prod`: 실제 주소로 배포합니다. 끝나면 `https://<이름>.netlify.app` 주소가 나옵니다.

수정한 뒤 다시 올릴 때는 `npx netlify-cli deploy --prod`만 다시 입력하면 됩니다.

## 4. 방법 B — GitHub 연결

이 폴더를 GitHub 저장소에 올리고, Netlify에서 **Add new project → Import an existing project**로 저장소를 연결합니다.
이후 GitHub에 올릴 때마다 자동으로 배포됩니다. (빌드 명령은 비워 두고, 배포 폴더는 `netlify.toml`에 이미 `public`으로 정해져 있습니다.)

## 5. 배포 후 설정 (Netlify → Project configuration → Environment variables)

| 이름 | 예시 | 설명 |
| --- | --- | --- |
| `ADMIN_PIN` | `여섯 자리 이상 숫자` | **필수.** 직원용 페이지 PIN. 없으면 직원 페이지가 열리지 않습니다 |
| `COUPON_DAYS` | `14` | 쿠폰 사용 기간(발급일 포함 일수). 기본 14일 |
| `COUPON_END` | `2026-12-31` | 캠페인 종료일. 이 날을 넘는 기한은 이 날로 맞춥니다 |
| `COUPON_ENABLED` | `false` | `false`로 두면 쿠폰을 발급하지 않고 퀴즈만 운영합니다 |

설정을 바꾼 뒤에는 한 번 더 배포해야 반영됩니다 (방법 A: `deploy --prod`, 방법 B: Deploys → Trigger deploy).

## 6. 매장별 주소와 QR

- 고객용: `https://<이름>.netlify.app/?store=gwanghwamun`
- 직원용: `https://<이름>.netlify.app/staff.html?store=gwanghwamun`

매장 코드는 `public/index.html`과 `public/staff.html`의 매장 목록(`gwanghwamun`, `gangnam`, `jamsil`)에서 추가·수정합니다.
댓글과 쿠폰 현황은 매장 코드별로 따로 모입니다. QR은 고객용 주소로 만듭니다.

## 7. 쿠폰 운영 흐름

1. 고객이 퀴즈 5문제를 모두 맞히면 `KT-XXXXXX` 형식의 쿠폰 번호가 발급됩니다 (한 기기에 한 번).
2. 계산할 때 고객이 화면을 보여 주면, 직원은 직원용 페이지 **쿠폰 확인**에 번호를 넣어 확인합니다.
3. "사용 가능한 쿠폰"이면 POS에서 할인을 적용하고 **사용 처리하기**를 누릅니다. 같은 번호는 다시 쓸 수 없습니다.

> 이 쿠폰 번호는 POS·교보문고 회원 쿠폰과 연결되어 있지 않습니다. 실제 할인은 직원이 POS에서 직접 적용해야 하므로, 시행 전 적용 대상·POS 처리 방법을 정해 주세요.

## 8. 시행 전 확인 사항

- **쿠폰 승인**: 할인율, 적용 대상, 다른 할인과의 중복 여부, 비용 부담 부서.
- **도서정가제**: 도서는 직접 할인 10% 이내, 마일리지 등 간접 할인을 합쳐 15% 이내로 제한됩니다. 기존 회원 혜택과 겹치면 한도를 넘을 수 있어, 도서를 대상에 넣는다면 꼭 확인이 필요합니다.
- **고객용 공개**: 교보문고 이름으로 고객 의견을 받는 페이지이므로 브랜드·정보보안·고객 의견 관리 기준을 유관부서와 맞춰 주세요.
- **댓글 관리 담당**: 직원용 페이지에서 숨김 처리를 누가, 얼마나 자주 확인할지 정해 주세요.
- **문구 확인**: `SETTINGS.coupon.target`의 `[적용 대상]`, 유의사항의 `[사용 조건]`을 확정 문구로 바꿔 주세요.

## 9. 보안·한계

- PIN 하나로 관리하는 간단한 구조입니다. PIN은 직원끼리만 공유하고, 운영이 끝나면 바꿔 주세요.
- 한 기기에 한 번 발급하지만, 다른 기기나 브라우저로는 다시 받을 수 있습니다.
- 댓글은 30초에 한 번, 금칙어가 들어간 글은 남길 수 없습니다. 금칙어는 `netlify/lib/store.mjs`에서 추가합니다.
